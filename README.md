# IGD-Orbit ERP System

**IGD Group ERP System** - Multi-branch electronics retail and service management platform.

## 🏗️ Project Structure

```
igd-orbit/
├── backend/          # NestJS API
├── frontend/         # React SPA
├── shared/           # Shared types and utilities
├── prd/              # Product Requirements Documents
└── .memory/          # AI memory files
```

## 🚀 Tech Stack

### Backend
- Node.js 20 LTS
- NestJS
- TypeScript
- Prisma ORM
- PostgreSQL 16
- Redis
- BullMQ

### Frontend
- React 18
- TypeScript
- Vite
- TanStack Query
- Zustand
- Tailwind CSS
- shadcn/ui
- Recharts

## 📦 Installation

```bash
# Install dependencies
npm install

# Run backend development server
npm run dev:backend

# Run frontend development server
npm run dev:frontend
```

## 🛠️ Development

```bash
# Build all
npm run build

# Run tests
npm run test:backend
npm run test:frontend

# Lint code
npm run lint

# Format code
npm run format
```
